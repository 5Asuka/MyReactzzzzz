## Context

这是一个尝试性项目，目标是使用 TypeScript + React 创建轻量级小工具。当前第一个工具是"灵活代办工具"——一个基于 Vite + React 的网页应用，搭配极简 Node.js 后端读写本地 JSON 文件实现数据持久化。数据总量小于 1000 字符，即开即用。

项目目前为空白状态，无任何现有代码或依赖。

## Goals / Non-Goals

**Goals:**
- 构建 Vite + React + TypeScript 前端应用
- 实现代办事项的增（添加）、查（列表）、改（编辑/标记完成）、删（删除）核心功能
- 使用本地 JSON 文件持久化数据（不依赖数据库）
- 极简后端（Express），仅提供读取和写入两个 API 端点
- 界面现代化、简约、响应式，支持黑暗模式

**Non-Goals:**
- 不实现筛选/搜索功能
- 不实现用户认证、多用户、云端同步
- 不实现复杂的日历、提醒、标签功能
- 不实现桌面打包（非 Electron）

## Decisions

| 决策 | 选择 | 理由 | 替代方案 |
|------|------|------|----------|
| 前端框架 | **React + TypeScript** | 用户指定需求，生态丰富，类型安全 | Vue（不符合用户指定） |
| 构建工具 | **Vite** | 快速冷启动、HMR 优秀，React 生态标配 | CRA（已不再维护） |
| 后端框架 | **Express (极简)** | 只需 2 个端点，Express 上手快、体积小 | Koa、Fastify（小项目无必要） |
| 持久化方式 | **本地 JSON 文件** | 数据 < 1000 字符，JSON 读写简单直接，删除文件即重置 | localStorage（浏览器隔离，不直观）；SQLite（太重） |
| 状态管理 | **React Context + useReducer** | 应用规模小，无需引入外部库 | Zustand、Redux（小项目过度设计） |
| UI 样式 | **纯 CSS (CSS Modules)** | 保持轻量、自定义灵活，减少打包体积 | Ant Design、MUI（打包体积大） |

## Risks / Trade-offs

| 风险 | 缓解措施 |
|------|----------|
| JSON 文件并发写入冲突 | 数据量极小（< 1000 字符），写入操作串行化处理 |
| 后端与前端需同时启动 | 使用 `concurrently` 同时启动前后端，或 vite proxy 代理 |
| 端口冲突 | 默认使用 3001 端口，支持环境变量配置 |
| JSON 文件损坏 | 写入时先写临时文件再重命名，确保原子性 |
